# Лабораторная работа: Введение в Entity Framework Core

* **Тема:** Гостиничный комплекс GrandHotel
* **Стек:** C#, .NET 10, Entity Framework Core, SQLite

Проект демонстрирует управление жизненным циклом данных гостиничного комплекса через ORM Entity Framework Core: базовый CRUD, отслеживание состояний сущностей через Change Tracker, настройку связей 1:N и 1:1, а также каскадное удаление.

---

## Структура моделей (Models)

1. **RoomCategory** - категория номеров (название, базовая стоимость).
   * Связь `1 : N` с таблицей номеров `Room` (у одной категории несколько номеров).
2. **Room** - номерной фонд отеля (номер комнаты, этаж, внешний ключ `RoomCategoryId`).
   * Связь `N : 1` с категорией.
   * Связь `1 : 1` с электронной ключ-картой `KeyCard`.
3. **KeyCard** - электронная мастер-карта доступа (код карты, дата выпуска, внешний ключ `RoomId`).
   * Связь `1 : 1` с номером (у каждого номера строго одна мастер-карта).

---

## Реализованные сценарии (Demos)

1. **CrudOperations.cs - Базовые операции CRUD:**
   * `Create`: создание нового номера и привязка к существующей категории.
   * `Read`: поиск записи по первичному ключу через метод `db.Rooms.Find()`.
   * `Update`: обновление свойства объекта в памяти без прямого вызова `Update()` (EF Core автоматически фиксирует изменения через трекер).
   * `Delete`: удаление номера из базы данных методом `db.Rooms.Remove()`.

2. **ChangeTracker.cs - Отслеживание состояний (Change Tracker):**
   * Демонстрация полного жизненного цикла сущности:
     `Detached` → `Added` → `Unchanged` → `Modified` → `Deleted` → `Detached`.

3. **Relationships.cs - Связи и каскадное удаление:**
   * Жадная загрузка (Eager Loading) через `Include(r => r.RoomCategory)` и `Include(r => r.KeyCard)`.
   * Создание связанного графа объектов (категория + номер + ключ-карта) одним вызовом `SaveChanges()`.
   * Каскадное удаление (Cascade Delete): при удалении категории база автоматически зачищает связанные номера и их ключ-карты.

## Запуск проекта

### Через терминал:
```bash
cd EFTemplate
dotnet run
```

### Через Visual Studio / Rider:
1. Открыть файл решения `EFTemplate.slnx`.
2. Запустить (`Ctrl + F5`).
3. База данных `ef_hotel.db` сформируется и заполнится данными автоматически.
